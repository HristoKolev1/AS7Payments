# Payment Service

Payment service for the **Enterprise E-commerce Platform**.

The service represents the payment component of the checkout workflow and separates payment-related functionality from the rest of the application.

## Responsibilities

- Payment-related operations
- Processing payment information
- Supporting the checkout workflow
- Integration with the order service
- Payment-related REST API operations

## Tech

Java · Spring Boot · Stripe API Integration

## Enterprise E-commerce Platform

This service is part of a larger microservices-based e-commerce system.
